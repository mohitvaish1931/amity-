Step 1 · Security Twin

Turn an OpenAPI spec into a testable security model

Sentinel X parses your API, maps who can reach which data, and derives machine-readable security laws with evidence and confidence. Everything is derived from the spec and your configuration; nothing is executed here.

  • Security TwinIdentities, roles, endpoints, resources and sensitive fields as one graph, with provenance on every edge.
  • Security ConstitutionLaws such as “a customer may read only their own orders”, each with scope, evidence and a confidence rating.
  • Test specificationsGiven / When / Expect cases the Test Lab plans against a sandbox you are authorized to test.

Data sensitivity

Why it matters: fields are classified by name with a stated reason. Override any classification and the laws update. Exposure of a sensitive field is a risk to test, not a finding.
